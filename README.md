# ForkliftCalibration

iPhone app for calibrating forklifts.

## Goals

- Walk through calibration step by step on the floor.
- Speed up calibration by having the app compute the new values instead of performing calculations by hand.
- Keep a record of past checks.

## Requirements

- iOS 18+, iPhone
- Xcode 27+ to build

## Build and run

1. Clone the repo and open `ForkliftCalibration.xcodeproj`.
2. Pick an iPhone simulator and press Run.
